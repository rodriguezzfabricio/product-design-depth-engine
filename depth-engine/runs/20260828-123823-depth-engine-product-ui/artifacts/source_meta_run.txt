output is hard to understand, which forces the copy-paste-to-a-second-chat
workaround described in M1.

End to End Optimization of Model Harnesses  (Yoonho Lee et al., Stanford IRIS).
Confirmed: changing the harness around a fixed LLM can swing performance 6× on the
same benchmark; prior methods over-compress feedback, destroying the execution
traces needed to blame specific harness decisions — so Meta-Harness keeps full source
+ logs and lets an agentic outer loop iteratively rewrite the harness. Beat hand-designed
harnesses incl. TerminalBench-2. Read fully; mine its method for this run's own loop.
T7 Anthropic's planner / generator / evaluator experiment
Three-agent harness vs solo agent building a 2D game maker. Verified details worth
stealing: no agent may plan, code, and grade itself; planner specs without over-
specifying implementation; generator works one-feature sprints, commits to git, self-
evaluates before handoff; evaluator QAs against a sprint contract negotiated before
code; feature list held as JSON, never Markdown (resists model corruption — never
remove or reorder, only flip incomplete → complete); git log as permanent memory. Solo
agent: broken toy, 20 min, $9. Harness: 6 h, $200, working polished app that caught
subtle UI bugs.

Frontier Product Exploration team, ~5 months: internal Electron app, 1M+ lines, 1,500+

cluster: a 100-line index instead of thousand-page manuals; isolated sandboxes;
monitoring on chosen metrics instead of static-test guessing; "janitor" agents that build
nothing and only enforce executable architecture rules.
